MetaMCP 提供了内置的 Google Workspace 集成，采用最小权限的 OAuth 2.0 PKCE 认证流程。它将 Gmail、Google Calendar、Google Drive、Google Docs 和 Google Sheets 工具作为原生 MCP 服务器（`GoogleWorkspace`）公开在命名空间和端点中。

<Note>
**无 Admin SDK 或全域委托（Domain-Wide Delegation）**：MetaMCP 采用基于用户级别的 OAuth 2.0 PKCE 授权，**不**使用 Google Workspace Admin SDK、服务账号（Service Accounts）或全网域委派。每个用户独立连接其 Google 账号。
</Note>

## 1. Google Cloud 项目配置

### 1.1 创建 GCP 项目并启用 API
1. 打开 [Google Cloud Console](https://console.cloud.google.com/)。
2. 创建新项目或选择现有项目。
3. 进入 **APIs & Services（API 和服务）** > **Library（库）**，启用以下 5 个 API：
   - **Gmail API**
   - **Google Calendar API**
   - **Google Drive API**
   - **Google Docs API**
   - **Google Sheets API**

### 1.2 配置 OAuth 同意屏幕
1. 进入 **APIs & Services** > **OAuth consent screen（OAuth 同意屏幕）**。
2. 选择 **User Type（用户类型）**：
   - **Internal（内部）**：推荐 Google Workspace 组织内部使用（无需外部验证）。
   - **External（外部）**：将发布状态设置为 **Testing（测试中）**，并在 **Test users（测试用户）** 中添加授权测试用户邮箱。
3. 填写必要的应用信息（应用名称、用户支持邮箱、开发者联系信息）。
4. 在 **Scopes（范围）** 步骤中添加所需的基础权限范围。

### 1.3 创建 OAuth 2.0 Web 客户端凭据
1. 进入 **APIs & Services** > **Credentials（凭据）**。
2. 点击 **Create Credentials（创建凭据）** > **OAuth client ID（OAuth 客户端 ID）**。
3. 选择 **Application type（应用类型）** 为 **Web application（Web 应用）**。
4. 设置名称（例如 `MetaMCP Google Integration`）。
5. 在 **Authorized redirect URIs（已授权的重定向 URI）** 中，填入公开回调地址：
   ```text
   https://<your-metamcp-domain>/integrations/google/callback
   ```
   *(本地开发环境为：`http://localhost:12008/integrations/google/callback`)*
6. 点击 **Create** 并复制生成的 **Client ID** 与 **Client Secret**。

## 2. 环境变量与令牌加密配置

在 `.env` 或部署环境中配置以下变量：

| 变量名 | 必填 | 说明 |
| --- | --- | --- |
| `APP_URL` | 是 | MetaMCP 实例的公开访问基础 URL（例如 `https://mcp.example.com` 或 `http://localhost:12008`），用于生成公共 OAuth 回调 URI。 |
| `GOOGLE_CLIENT_ID` | 是 | 从 Google Cloud Console 获取的 Web OAuth Client ID。 |
| `GOOGLE_CLIENT_SECRET` | 是 | 从 Google Cloud Console 获取的 Web OAuth Client Secret。 |
| `GOOGLE_TOKEN_ENCRYPTION_KEY` | 条件必填 | 32 字节字符串或 64 字符十六进制字符串，用于 AES-256-GCM 令牌加密存储。 |
| `GOOGLE_TOKEN_ENCRYPTION_KEYS` | 可选 | JSON 格式的版本密钥映射，用于平滑轮换密钥，例如 `{"1":"key1_hex","2":"key2_hex"}`。 |
| `GOOGLE_TOKEN_ENCRYPTION_KEY_VERSION` | 可选 | 使用多版本密钥时，指定新加密采用的主版本号（例如 `"2"`）。 |

### 令牌加密与密钥轮换机制
- 用户令牌在数据库中采用 **AES-256-GCM** 加密存储，每条记录携带唯一的 12 字节 IV 和认证标签。
- **单密钥模式**：配置 `GOOGLE_TOKEN_ENCRYPTION_KEY`（32 字节或 64 字符十六进制），默认版本为 `1`。
- **多版本轮换模式**：配置 `GOOGLE_TOKEN_ENCRYPTION_KEYS` 包含所有历史与当前密钥，并设置 `GOOGLE_TOKEN_ENCRYPTION_KEY_VERSION`。系统解密时自动根据载荷中记录的版本匹配对应密钥，无需停机迁移。

```bash .env
APP_URL=https://mcp.example.com
GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-client-secret
GOOGLE_TOKEN_ENCRYPTION_KEY=0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
```

## 4. 命名空间安全与默认非激活机制

- **默认非激活（Default Inactive）**：`GoogleWorkspace` 提供的所有工具在加入命名空间时默认为 **`INACTIVE`** 状态。
- **逐项启用**：必须在命名空间工具列表中手动开启所需的工具。
- **前缀隔离**：所有 Google Workspace 工具均带有命名空间前缀 `GoogleWorkspace__<tool_name>`（例如 `GoogleWorkspace__gmail_search`）。
- **用户作用域执行**：工具执行时基于当前调用用户的 Google 连接令牌运行；未连接用户将收到 `GoogleWorkspaceError("NOT_CONNECTED")`。

## 5. 客户端连接指南

### 方式 A：ChatGPT（纯 OAuth 远程 MCP）
1. 在 MetaMCP 中导航至 **Endpoints（端点）**，找到指向 Google Workspace 命名空间的端点。
2. 确保端点设置中 **OAuth Auth** 处于启用状态。
3. 复制端点 URL：
   ```text
   https://<your-metamcp-domain>/metamcp/<endpoint-name>/mcp
   ```
4. 在 ChatGPT（或 Custom GPT Action / MCP 连接器）中：
   - 认证类型选择 **OAuth**。
   - ChatGPT 会通过 `/.well-known/oauth-authorization-server` 自动发现授权与令牌端点。
   - 在弹出的浏览器窗口中完成 MetaMCP 授权。

### 方式 B：Hermes / OpenCode / Agent CLI（API Key 或 OAuth）

#### 1. API Key 认证方式（Streamable HTTP / STDIO 代理）
```json
{
  "mcpServers": {
    "MetaMCP-Google": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-proxy",
        "https://<your-metamcp-domain>/metamcp/<endpoint-name>/mcp"
      ],
      "env": {
        "METAMCP_API_KEY": "your-metamcp-api-key"
      }
    }
  }
}
```

#### 2. OAuth 认证方式（使用 `mcp-remote`）
```json
{
  "mcpServers": {
    "MetaMCP-Google": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://<your-metamcp-domain>/metamcp/<endpoint-name>/mcp"
      ]
    }
  }
}
```

## 6. 断开连接与撤销授权

用户可随时断开并撤销 Google 连接：
1. 打开 MetaMCP 界面中的 **Settings** > **Google Workspace**。
2. 点击 **Disconnect Google Workspace**。
3. **处理流程**：
   - MetaMCP 向 `https://oauth2.googleapis.com/revoke` 发送请求撤销 Google 端令牌。
   - 数据库中的加密令牌记录被彻底删除。
   - 该用户的所有后续 Google Workspace 工具调用立即失效，直到重新连接。
